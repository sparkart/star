📘 SparkArt Guidebook

คู่มือฉบับสมบูรณ์ — ระบบผลิตคอนเทนต์ดูดวงอัตโนมัติด้วย AI

📊 ภาพรวม

SparkArt คือระบบผลิตคอนเทนต์ดูดวงอัตโนมัติ (AI Horoscope Affiliate Pipeline) ที่ใช้ Swiss Ephemeris คำนวณตำแหน่งดาวจริง + AI เขียนบทภาษาไทย + TTS แปลงเป็นเสียงพากย์ โดยมีเป้าหมายสร้างรายได้จาก Affiliate แบบไม่ต้องทำคอนเทนต์เองทุกวัน

องค์ประกอบหลัก:

  • 🔮 Astrology Engine — คำนวณดวงด้วย Swiss Ephemeris (pyswisseph)
  • ⚙️ AI Pipeline — DeepSeek/Claude เขียนบท + Google Chirp3 TTS
  • 🎬 Video Pipeline — CapCut automation + FFmpeg render
  • 💰 Monetization — Affiliate links + โซเชียลมีเดีย

🔮 Astrology Engine

หัวใจของระบบคือการคำนวณดวงที่แม่นยำระดับวิทยาศาสตร์ด้วย Swiss Ephemeris ซึ่งเป็นไลบรารีมาตรฐานที่นักโหราศาสตร์มืออาชีพใช้ทั่วโลก

สิ่งที่คำนวณได้

  • ตำแหน่งดาว 10 ดวง (อาทิตย์ จันทร์ อังคาร พุธ เสาร์ ราหู ฯลฯ)
  • ราศีที่ดาวสถิต (Aries, Taurus, ... Pisces)
  • เรือนที่ดาวอยู่ (House 1-12)
  • Aspects ระหว่างดาว (Conjunction, Trine, Square, Opposition)
  • คะแนน 4 ด้าน: การงาน, การเงิน, ความรัก, สุขภาพ

ไฟล์สำคัญ

  • astro_daily_pro.py — คำนวณดวงรายวันจาก Swiss Ephemeris
  • daily_horoscope_v2.py — แปลงข้อมูลดาราศาสตร์เป็นคะแนน 4 ด้าน 7 วันเกิด

⚙️ AI Pipeline

เมื่อได้ข้อมูลดวงแล้ว ขั้นตอนต่อไปคือการแปลงเป็นบทภาษาไทยที่อ่านสนุกและเป็นธรรมชาติ

AI Writer

  • DeepSeek (หลัก) — horoscope_ai_writer_v2.py เขียนบทภาษาไทย ต้นทุน ~฿0.016/บท
  • Claude (พรีเมียม) — ai_writer_claude.py คุณภาพสูงกว่า แต่ต้นทุนสูงกว่า
  • Fallback — template สำรองกรณี API ล่ม

TTS (Text-to-Speech)

  • Google Chirp3 HD — เสียงไทยธรรมชาติ ฟังแล้วไม่รู้ว่า AI
  • ปรับ speaking_rate ได้ (0.85-1.05) ให้ฟัง "เคลิ้ม"

🎯 Brand Strategy

การสร้างแบรนด์ดูดวงให้แตกต่างจากคู่แข่ง ด้วยจุดแข็ง "แม่นด้วยวิทยาศาสตร์" ไม่ใช่ "มโนแบบหมอดู"

จุดขาย

  • ใช้ Swiss Ephemeris จริง — ไม่ใช่ Random
  • AI เขียนบทเฉพาะบุคคล — ไม่ใช่ Template ซ้ำ
  • เสียงพากย์ธรรมชาติ — ไม่ใช่ TTS หุ่นยนต์
  • ผลิตอัตโนมัติ — สเกลได้ไม่จำกัด

กลุ่มเป้าหมาย

  • สายมู Gen Y/Z — ดูดวงใน TikTok/YouTube Shorts
  • คนทำงาน — ดูดวงการงาน/การเงินรายวัน
  • คนไทยในต่างประเทศ — เนื้อหาภาษาไทย

💰 Monetization

โมเดลรายได้ของ SparkArt มีหลายชั้น:

ชั้นที่ 1: Affiliate (ปัจจุบัน)

  • แทรกลิงก์สินค้ามงคลในวิดีโอ (กำไลหิน, สร้อย, เครื่องราง)
  • Shopee/TikTok Affiliate
  • รายได้ต่อวิดีโอ: ~฿50-500 ขึ้นอยู่กับยอดวิว

ชั้นที่ 2: โซเชียลมีเดีย (เร็วๆ นี้)

  • YouTube Shorts — monetization จากยอดวิว
  • TikTok Creator Fund
  • LINE OA — subscription รายเดือน

ชั้นที่ 3: Licensing (อนาคต)

  • ขาย API ให้เว็บดูดวงอื่น
  • White-label ให้เอเจนซี่

📈 Growth

แผนการเติบโตใน 6-12 เดือน:

  1. Bulk Generation — ผลิต 180 วัน × 7 วันเกิด = 1,260 วิดีโอ ต่อเดือน
  2. Multi-Voice — ใช้เสียง Chirp3 หลายแบบ ลด pattern detection
  3. Auto-Upload — Publish อัตโนมัติไปทุกแพลตฟอร์ม
  4. A/B Testing — ทดลอง hook/thumbnail หลายแบบ หา best performer
  5. Analytics Dashboard — ติดตามยอดวิว รายได้ ต่อวิดีโอ

❓ FAQ

ทำไมต้องใช้ Swiss Ephemeris?

เพราะเป็นไลบรารีดาราศาสตร์มาตรฐานที่ NASA และนักโหราศาสตร์มืออาชีพใช้ — คำนวณตำแหน่งดาวแม่นระดับวินาที ไม่ใช่ Random เหมือนเว็บดูดวงทั่วไป

ใช้ AI อะไรเขียนบท?

ปัจจุบันใช้ DeepSeek เป็นหลัก (ถูกมาก ~฿0.016/บท) และกำลังทดลอง Claude สำหรับบทคุณภาพสูง ระบบมี fallback template กรณี API ล่ม

เสียงพากย์ธรรมชาติแค่ไหน?

Google Chirp3 HD เป็น TTS ที่ดีที่สุดสำหรับภาษาไทย — คนฟังไม่รู้ว่าเป็น AI ถ้าไม่บอกล่วงหน้า

ต้องลงทุนเท่าไหร่?

ต้นทุนต่ำมาก: DeepSeek ~฿0.016/บท + TTS ~฿0.02/นาที + Render ~฿0.01/วิดีโอ = ~฿0.30/วิดีโอ — คุ้มทุนตั้งแต่เดือนแรก

เผยแพร่ที่ไหน?

YouTube Shorts, TikTok, LINE OA, Facebook — ครบทุกแพลตฟอร์มใน pipeline เดียว
