ค่าลับถูกเก็บไว้ที่เซิร์ฟเวอร์เท่านั้น

ฟอร์มในหน้านี้จะไม่เติมค่าเดิมให้อัตโนมัติ และ API จะไม่ส่งค่าลับกลับมาไม่ว่ากรณีใด สิ่งที่แสดงได้มีเพียงสถานะและตัวอักษรท้ายไม่กี่ตัวเพื่อยืนยันว่าบันทึกไว้แล้ว ไฟล์ทั้งหมดถูกเขียนด้วยสิทธิ์ 0600 ในไดเรกทอรีสถานะ

Claude ใช้การล็อกอินของ CLI บนเซิร์ฟเวอร์ (claude login) ระบบนี้ไม่รับ session token ของ Claude ผ่านเบราว์เซอร์

ปลายทางที่ต้องอัปโหลดเองจะไม่ถูกรายงานว่าเผยแพร่สำเร็จ และตั้งเวลาอัตโนมัติไม่ได้ที่ หน้าตารางเวลา
